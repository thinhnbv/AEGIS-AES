Request Frame (PC → FPGA) - 36 bytes

BytesFieldDescription
00xA5Preamble marker
1CMDCommand (0x01 = AES)
2SEQSequence number
3-18KEY[15:0]16-byte AES key
19-34DATA[15:0]16-byte plaintext/ciphertext
35XORChecksum (XOR of bytes 0-34)

Response Frame (FPGA → PC) - 37 bytes

BytesFieldDescription
00x5APreamble marker
1SEQEchoed sequence
2FLAGSStatus flags
3SEC_STATUSSecurity status
4-19RESULT[15:0]16-byte AES result
20-35PROTECTED[15:0]Protected output
36XORChecksum
